# Project Context

This repository is a modern TypeScript application. Source code is under `src/`, tests are under `tests/`, and documentation is under `docs/`.

## Rules

- Use npm for all package commands.
- Always write clean, maintainable code and follow TypeScript best practices.
- Always run the full test suite after every edit.
- Never edit `src/generated/`; run the generator instead.
- We are currently migrating billing to the new service.
- For billing unit tests, run `pnpm test:billing`.
