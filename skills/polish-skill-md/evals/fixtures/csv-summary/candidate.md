# CSV Summary

Given an existing CSV or TSV data file:

1. Compute descriptive statistics for numeric columns.
2. Report missing-value counts.
3. Create a chart when the user asks for a visualization.
4. Preserve the input and write derived output to a new file.

This skill does not implement database loading or edit spreadsheet formulas and formatting.
